# CodingSchoolFront

Front-end de la **Coding School** (NEOMA Business School) — interface harmonisée avec les plateformes **Excel Mastery** et **NEOSmart**.

## Pages

- `index.html` — Accueil (bannière « En maintenance », étapes, langages, chiffres)
- `login.html` — Connexion (identifiant = e-mail institutionnel `@neoma-bs.com`, lien « Mot de passe oublié »)
- `dashboard.html` — Tableau de bord élève (progression, cours en cours, certifications)
- `depot.html` — Dépôt de rendu de projet
- `ateliers.html` — Ateliers NEOSmart (message « Confirmation validée » à la réservation)

Ouvrir `index.html` dans un navigateur (site statique, aucune dépendance serveur).
